# Finanças.

Controle financeiro pessoal, com a mesma cara do Health Log: tudo em **janelas flutuantes** que você arrasta, redimensiona, fixa (alfinete) e que ficam onde você deixou. Contas do mês, rendas (dia 1 pagamento, dia 30 VA), gastos do dia a dia, calendário, metas e um assistente que avisa quando você está gastando demais.

App web instalável (PWA), sem servidor: os dados ficam **só no aparelho** (localStorage), com cópias automáticas e exportação em arquivo.

- **Abrir:** servir a pasta por http(s) — por exemplo `python3 -m http.server 8080` — e acessar `http://localhost:8080`. No GitHub Pages: Settings → Pages → branch `main`, pasta `/`.
- **iPhone:** abrir o endereço no Safari → Compartilhar → Adicionar à Tela de Início.
- **Testes:** `node testes/regressao.js` (precisa do Playwright).

Veja `CLAUDE.md` para as regras do projeto.
